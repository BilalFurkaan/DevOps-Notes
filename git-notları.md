# Git Temel Notlar

## Temel Git Döngüsü
| Komut | Açılımı | Ne Yapar |
|-------|---------|----------|
| `git init` | Initialize | Repoyu başlatır |
| `git add` | Add | Dosyayı sahneye alır |
| `git commit` | Commit | Değişiklikleri kaydeder |
| `git push` | Push | GitHub'a gönderir |
| `git status` | Status | Değişiklikleri gösterir |
| `git log` | Log | Commit geçmişini gösterir |

## Branch Komutları
| Komut | Ne Yapar |
|-------|----------|
| `git branch` | Branch listesini gösterir |
| `git branch isim` | Yeni branch oluşturur |
| `git checkout isim` | Branch'e geçer |
| `git merge isim` | Branch'i birleştirir |
